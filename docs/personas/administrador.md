# Persona: Administrador

## Perfil
Gestor do sistema de recursos.

## Objetivo
Administrar de forma centralizada o conjunto de recursos, permissões e regras operacionais do sistema para garantir organização, disponibilidade e controle institucional.

## Ações permitidas
- Cadastrar salas.
- Editar salas.
- Excluir salas.
- Cadastrar materiais.
- Editar materiais.
- Excluir materiais.
- Cadastrar equipamentos.
- Editar equipamentos.
- Excluir equipamentos.
- Cadastrar usuários/professores.
- Editar usuários/professores.
- Excluir usuários/professores.
- Definir bloqueios de agenda.
- Alterar bloqueios de agenda.
- Remover bloqueios de agenda.
- Cadastrar horários e períodos de manutenção.
- Gerenciar manutenção e disponibilidade dos recursos.
- Definir permissões do sistema.
- Alterar parâmetros do sistema.
- Gerenciar todas as configurações administrativas necessárias ao funcionamento do sistema.

## Restrições
- Nenhuma restrição operacional relevante dentro do escopo administrativo do sistema.
- Deve atuar com responsabilidade para preservar integridade dos dados e disponibilidade dos recursos.

## Necessidades principais
- Manter o cadastro atualizado de salas, materiais, equipamentos e usuários.
- Garantir que os bloqueios e manutenções sejam registrados corretamente.
- Administrar permissões para manter o sistema seguro e adequado ao nível de acesso de cada perfil.
- Preservar a operação contínua e organizada dos recursos institucionais.
